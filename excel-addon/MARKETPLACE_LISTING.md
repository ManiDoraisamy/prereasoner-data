# Microsoft Marketplace listing draft

**Product name**  
Prereasoner - Excel Copilot

**Short description**  
Ask questions about your Excel workbook in plain language and inspect the rows and reasoning behind each answer.

**Description**  
Prereasoner - Excel Copilot lets you ask a question about the workbook you already have open. Review the answer, inspect the supporting rows and calculation steps, then continue with follow-up questions or reopen a previous conversation.

**Features**

- Ask spreadsheet questions in plain language—no formulas or query language to learn.
- Analyze related data across visible worksheets.
- Inspect the source rows and calculation steps behind an answer.
- Continue a conversation with follow-up questions and reopen saved analyses.
- Keep the source workbook unchanged: the add-in reads workbook data when you submit a question and does not edit cells.
