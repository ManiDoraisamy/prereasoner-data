# Evaluation source

- Source: CUAD v1, The Atticus Project, `Label Report - Termination for Convenience.xlsx`.
- License: Creative Commons Attribution 4.0 International (CC BY 4.0).
- URL: https://huggingface.co/datasets/theatticusproject/cuad
- Shipped workbook: a 183-row structured projection of that report with `contract_name`, `notice_days`, and `clause_type`. `notice_days` is the first explicit numeric `N days` value in the source clause; rows without one remain blank.
- Purpose: Formesign-style contract-review and document-register evaluation only; not a home-page example and not a training corpus.
